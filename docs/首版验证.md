## 实现与原计划的区别

首版波形采用 WPF DrawingContext 自绘，约 20 FPS；按水平像素保留极值。SerialPort 的打开、读、写、关闭由一个后台线程管理，不使用 DataReceived。原图主面板加 WPF 主题辅助面板，可浮动；未实现完整九宫格辅助皮肤与磁性吸附。UI code-behind 与 Core / IO 分层，未完成完整 MVVM 重构。

## 未验证 / 尚未实现

- 发布检查时 `SerialPort.GetPortNames()` 返回空数组。没有对真实串口进行发送、回环、端口占用、拔插或驱动测试。
- 未执行原计划 8 通道 × 10 ksample/s、持续 30 分钟的压力验收；测试通过不等于该性能目标已达成。
- 未完成 125% / 150% / 200% 等所有 DPI 与全部 69 款皮肤逐控件外观验收。
- 尚无触发、双游标、FFT、二进制协议、录制回放、系统托盘和独立安装器。CSV 是原始数值，显示换算配置另存于录制会话 JSON。
